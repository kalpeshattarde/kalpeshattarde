## How I Approach Automation

1. Understand the business process and identify repetitive work.
2. Map the workflow, data sources, systems, and failure points.
3. Build automation with validation, retries, and error handling.
4. Add logs, monitoring, alerts, and human review where required.
5. Document the system so the business can maintain and scale it.
